# Sensor Mount STLs

3D-printable mounting hardware for attaching the Robosense AIRY LiDAR and ZED camera to the Kobuki robot base.

## Design Assumptions

These mounts are designed around the following physical constraints:

| Parameter | Value |
|---|---|
| **Robot base** | Kobuki |
| **Mounting hole grid** | 19 mm × 19 mm spacing |
| **Mounting hole diameter** | 5 mm |
| **LiDAR mounting plate** | 100 mm × 100 mm aluminum plate |

> **Note:** If your Kobuki variant has a different hole pattern, or if your LiDAR uses a different base plate size, the STL files will need to be modified before printing.
